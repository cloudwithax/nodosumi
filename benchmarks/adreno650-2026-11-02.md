Retroid Pocket 5 / Adreno 650 — 2026-11-02
========================================

Installed and tested over ADB. The final installed APK is the normal signed
release build. All 17 original system/save/settings files matched their
pre-install SHA-256 hashes after testing. A full app-data backup and raw test
artifacts remain in `/tmp/nodosumi-benchmark/` on the build host.

The workload is a save-state replay of Crazy Taxi 2's 3D attract driving
sequence. It is not an interactive gameplay benchmark. Bot Start presses
reached both the emulated controller state and guest memory, but did not
reliably enter a play session in this setup. That issue remains unresolved.

Each run restores the same state at core frame 120, warms up for 180 frames,
and measures frames 300–899: 600 frames / approximately 10 seconds. Every run
averaged 369.45 draw calls and 12,301.24 submitted vertices per rendered frame.
No measured display intervals exceeded 25 ms and no trace events were dropped.
Battery temperature stayed approximately 28°C. GPU clocks were not locked.

| Configuration | Emulation FPS | Mean core GPU draw | P95 core GPU draw |
|---|---:|---:|---:|
| 1×, 640×480, 4:3 | 60.00 | 0.458 ms | 0.731 ms |
| 2×, 1280×960, 4:3 | 60.00 | 0.827 ms | 1.220 ms |
| 4×, 2560×1920, 4:3 | 60.01 | 2.037 ms | 2.754 ms |
| 4× widescreen, optimizations disabled, run 1 | 59.99 | 1.953 ms | 2.664 ms |
| 4× widescreen, optimizations enabled, run 1 | 59.99 | 1.618 ms | 2.283 ms |
| 4× widescreen, optimizations disabled, run 2 | 60.00 | 1.945 ms | 2.651 ms |
| 4× widescreen, optimizations enabled, run 2 | 60.00 | 1.608 ms | 2.272 ms |

The two-run mean core GPU draw time fell from 1.949 ms to 1.613 ms, a **17.2%**
reduction in this scene. P95 draw time fell approximately 14.3%. FPS stayed
at the frontend's 60 Hz pacing limit; this is improved GPU headroom, not an
observed FPS increase. Widescreen targets use 2560×1440 instead of storing a
2560×1920 image with unused letterboxing: 25% less attachment storage.

The A/B switch changes only the new framebuffer optimizations in the same
optimized native binary: trimmed 16:9 targets, RTT depth/stencil discard, and
skipping redundant full-screen presentation clears. Expansion is enabled in
both widescreen cases. Order was optimized/baseline, then baseline/optimized.
The 4:3 runs characterize scaling; they are not an A/B comparison.

GPU timer queries cover core draws. They exclude the final Android presentation
blit; `android_present` trace spans measure CPU submission/blocking, not GPU
execution. The profiling APK has debuggable ART and tracing overhead. The
native compiler optimization flags match release (`-O2 -DNDEBUG`). Short runs
and a single scene do not establish sustained thermals or performance in other
games. Native input/rumble state and rendering regression tests passed on the
same Adreno device; physical motor output and controller feel remain unverified.
